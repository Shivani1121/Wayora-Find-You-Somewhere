
# 🌿 Wayora — Find Your Somewhere

> For the places you've saved, the places you've dreamed of, and the places you haven't met yet.

**Wayora** is an aesthetic, responsive travel discovery website designed to inspire your next adventure. Explore beautiful destinations, save your favourite places, browse travel inspiration, and create a simple trip plan with estimated costs.

## ✨ Features

- 🌍 **Explore destinations** — Discover 30 destinations across different countries and regions.
- 🔎 **Search and filters** — Find places by city, country, region, or travel vibe.
- 💗 **Favourite destinations** — Save and unsave places using the heart button.
- 🖼️ **Travel inspiration** — Browse a visual gallery of beautiful places.
- 🧳 **Trip planner** — Select a destination, travel duration, group size, and travel style.
- 💰 **Budget estimates** — View approximate trip costs in Indian rupees (INR).
- 🗺️ **Route suggestions** — Get general guidance for planning your journey.
- 📱 **Responsive design** — Designed for desktop, tablet, and mobile screens.
- 🔐 **Login interface** — Includes a front-end demonstration of a login form.
- 🌸 **Elegant UI** — Cream, sage green, blush pink, and gold-inspired styling.
- 🖼️ **Image fallbacks** — Provides visual fallbacks when external destination images fail to load.

## 🚀 Getting Started

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` using the Live Server extension, or open the HTML file directly in your browser.
4. Make sure you have an internet connection for external images and fonts.

No package installation or build tools are required.

## 🧭 How to Use

1. Browse the destination cards.
2. Search for a city or country.
3. Select a category to filter destinations.
4. Click the heart icon to favourite a destination.
5. Choose **Plan a trip** or open the trip planner.
6. Select your travel duration, group size, and travel style.
7. Review the estimated budget and general route suggestions.

## 💸 Budget Disclaimer

Trip costs are illustrative estimates in INR, not live travel prices. Actual expenses depend on departure location, dates, accommodation, transportation, exchange rates, and availability. Route suggestions are general guidance, not live navigation.

## 🔐 Login Disclaimer

The login interface is for demonstration purposes only. It does not provide real authentication or create user accounts. A secure authentication service would be needed for production use.
